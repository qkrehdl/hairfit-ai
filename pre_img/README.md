MediaPipe Face Mesh를 사용하여 이미지 파일에서 얼굴의 주요
랜드마크를 추출하고, 이를 기반으로 얼굴 길이(L), 얼굴 폭(W), 턱 폭(J) 간의 비율을 계산합니다. 계산된 비율은 실제 얼굴형 분류 기준을 통계적으로 분석하고 임계값(Threshold)을 설정하는 데 사용됩니다. 

<MediaPipe Face Mesh>
google에서 개발한 얼굴 랜드마크 감지 솔루션입니다.
얼굴의 굴곡과 세부 구조를 실시간으로 포착하는 기술입니다.
얼굴 표면에 존재하는 약 400개의 3차원 랜드마크를 실시간으로 추적하고 모델링하는 머신러닝 기반 프레임워크입니다.
Face Mesh의 랜드파크는 얼굴 윤곽뿐만 아니라 눈썹, 눈, 코, 입술 등 세부적인 굴곡과 특징점을 모두 포함하여 총 478개의 점을 찍어냅니다.

pre.py는 이 랜드마크들 사이의 최단 거리를 계산하여 얼굴의 절대 크기가 아닌 비율에 기반한 분석을 수행합니다. 이는 카메라의 거리에 관계없이 일관된 분석 결과를 얻는데 도움을 줍니다.

pre.py에서는 L(얼굴 길이), W(얼굴 폭), J(턱 폭) 랜드마크를 사용하여 L/W, J/W 비율을 추출합니다.


<주요 기능>
MediaPipe Face Mesh를 이용한 정확한 얼굴 랜드마크 추출.
얼굴 길이-폭 비율 (L/W Ratio) 및 턱 폭-얼굴 폭 비율 (J/W Ratio) 계산.
분석 결과를 CSV 파일로 저장하여 통계 분석 용이성 확보.


<측정 기준이 되는 랜드마크 인덱스>
스크립트는 다음 랜드마크 인덱스를 사용하여 주요 거리를 계산.

랜드마크 측정 요소               거리 정의                  인덱스  

얼굴 길이(L)            미간 중앙 - 턱 끝 (세로 길이)       10 - 152
얼굴 폭(W)                  광대 좌 - 광대 우             35 - 265
턱 폭(J)                    하관 좌 - 하관 우             58 - 288


<설치 및 실행 방법>
1. 환경 설정
이 스크립트를 실행하려면 Python 3 환경이 필요하며, 다음 라이브러리를 설치해야 합니다.
pip install opencv-python mediapipe numpy pandas

2. 스크립트 실행준비가 완료되면, 터미널/명령 프롬프트에서 스크립트를 실행합니다.
python pre.py

결과 파일스크립트 실행이 완료되면, 현재 디렉토리에 face_shape_analysis_results.csv 파일이 생성됩니다.

열 이름                         설명
filename                분석된 이미지 파일 이름
face_type              이미지의 원래 분류 폴더 이름
face_detected    MediaPipe가 얼굴을 성공적으로 감지했는지 여부
L_W_Ratio             얼굴 길이 / 얼굴 폭 비율
J_W_Ratio               턱 폭 / 얼굴 폭 비율


<결과 활용>
이 CSV 파일을 통해 각 얼굴형(face_type)별로 L_W_Ratio와 J_W_Ratio의 평균값, 분산, 분포를 확인하여, 자동으로 얼굴형을 분류할 수 있는 통계적인 임계값을 설정할 수 있습니다.
