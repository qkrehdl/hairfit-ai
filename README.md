[index.html]
- 개요
google의 MediaPipe Facd Mech 라이브러리를 활용하여 얼굴의 주요 랜드마크를 추출하고, 미리 정의된 비율을 기반으로 규칙 기반 분류를 수행합니다. 분석된 얼굴형에 따라 성별에 맞는 맞춤형 결과 페이지로 이동합니다.

- 기능 및 특징
실시간 웹캠 분석: 사용자의 얼굴을 웹캠으로 받아 실시간으로 MediaPipe가 랜드마크를 추적합니다.

성별 기반 분석: pre.py를 실행하여 얻은 csv 파일을 통해 성별에 따라 다른 임계값을 정하고,성별에 따라 임계값을 적용합니다.

규칙 기반 분류: 얼굴의 주요 비율을 계산하여 미리 설정된 규칙에 따라 얼굴형을 4가지 유형으로 분류합니다.
    - 분류 순서: 각진형 -> 긴형 -> 둥근형 -> 계란형

시각적 피드백: 웹캠 화면에 얼굴 랜드마크와 윤곽선을 실시간으로 표시하여 분석 과정을 시각적으로 보여줍니다.

- 얼굴형 분류 로직
길이 대 폭 비율 (L/W): 얼굴 길이(이마 중심 -> 턱 끝) / 얼굴 폭(양 볼)

- 턱 폭 대 폭 비율 (J/W): 턱 폭(양 턱선) / 얼굴 폭(양 볼)

- 코드 구조 및 함수

showGenderButtons(): 분석 시작 버튼 클릭 시 성별 선택 영역을 표시

startProcess(gender): 성별을 저장하고 MediaPipe 초기화 및 웹캠 스트림 시작 함수(initMediaPipe)를 호출

initMediaPipe(): 웹캠 접근 권한을 요청하고, MediaPipe Face Mesh 모델을 로드하여, 실시간 프레임 전송을 시작

sendToFaceMesh(): 웹캠 비디오 프레임을 캔버스에 좌우 반전(미러링)하여 그린 후, MediaPipe로 전송하는 반복 함수

onResults(results): MediaPipe 분석 결과를 처리합니다. 랜드마크를 캔버스에 그리고, 비율을 계산하여 classifyFaceShape를 호출

calculateDistance(p1, p2): 두 랜드마크 사이의 거리를 계산

classifyFaceShape(1_w_ratio, j_w_ratio, gender): 계산된 비율과 성별 임계값을 기반으로 최종 얼굴형을 결정

finishPrediction(): 10초 타임아웃 후 호출되거나 분석이 완료되면 호출.
웹캠 스트림을 중지하고 최종 결과를 쿼리 스트링으로 담아 성별에 맞는 결과 페이지로 리다이렉션함.


- 실행 순서
1. 웹 서버를 통해 열기
2. 분석 시작 버튼 클릭
3. 여성 또는 남성 선택
4. 웹캠 접근 허용
5. 웹캠 화면에 얼굴을 맞춰 분석이 완료되기를 기다리기
6. 10초 후 결과 페이지로 이동


[result_F.html] [result_M.html]
- 개요
앞서 실행된 index.html에서 성별로 분류된 결과를 받아와 해당 얼굴형에 대한 상세 특징 및 맞춤형 헤어스타일 추천 정보를 사용자에게 제공하는 결과 페이지입니다. URL 쿼리 파라미터를 통해 전달된 얼굴형 레이블에 따라 화면 콘텐츠가 동적으로 변경됩니다.

- 주요 기술 및 구성 요소
    - HTML5/CSS3: 페이지 구조 및 모바일 반응형 디자인

    - JavaScript: URL 쿼리 파라미터(?label=)를 읽어 분석된 얼굴형을 확인
                resultData 객체에서 해당 얼굴형에 맞는 특징, 전략, 추천 이미지 경로를 불러와 DOM에 동적 출력    

    - 데이터 구조(resultData):
        얼굴형(Key): 둥근형, 긴형, 각진형, 계란형
        추천 이미지(recommendationImages): 얼굴형별 추천 헤어스타일 이미지 파일 경로(3개)
        특징(features): 얼굴형에 대한 설명 및 대표 연예인
        전략(strategies): 헤어스타일 추천 핵심 전략(목록)


- 페이지 핵심 기능: 
1. 동적 결과 출력: URL에서 $label 값을 추출하여 "_ _ _얼굴형"이라는 최종 진단 결과를 화면에 표시
2. 맞춤형 추천: 얼굴형(label)에 따라 resultData에서 정의된 세 가지 정보(특징, 전략, 이미지)를 로드
3. 페이지 이동 버튼: 
    처음으로: 메인 페이지(index.html)로 이동
    다른 얼굴형 헤어스타일 추천 보기: 다른 얼굴형들의 추천 스타일을 모아둔 페이지(result_F.html에서는 other_F.html, result_M.html에서는 other_M.html)로 이동


- JavaScript 동작
resultData: 각 얼굴형에 대한 모든 콘텐츠 정보를 담고 있는 핵심 객체

label: URLSearchParams를 사용하여 index.html에서 전달된 최종 분석 결과 값을 저장

동적 출력 로직: label을 키로 사용하여 resultData[label]에 접근, 결과를 document.getElementById를 이용해 ```<div id="result">, <div id="feature-content">, <ul id="strategy-content">``` 등에 삽입

이미지 갤러리: data.recommendationImages 배열을 순회하며 ```<img class="recommend-image">``` 태그를 동적으로 생성하여 ```<div id="image-gallery">```에 추가

goToHome(): 사용자를 분석 시작 화면으로 되돌림

goToOtherStyles(): 여성 혹은 남성의 다른 모든 얼굴형의 추천 목록 페이지로 이동



[other_F.html] [other_M.html]
- 개요
모든 얼굴형에 대한 헤어스타일 추천 정보를 한 페이지에 모아 제공하는 페이지입니다. 사용자가 탭 메뉴를 클릭하여 원하는 얼굴형 특징, 추천 이미지, 스타일링 전략을 쉽게 열람할 수 있도록 탭 방식으로 구현되었습니다.

other_F.html은 result_F.html에서 '다른 얼굴형 헤어스타일 추천 보기' 버튼을 클릭했을 때 접근되고, 
other_M.html은 result_M.html에서 '다른 얼굴형 헤어스타일 추천 보기' 버튼을 클릭했을 때 접근됩니다.

- 주요 기술 및 구성 요소
    - HTML_5/CSS3: 페이지 구조 및 모바일 반응형 디자인
    - JavaScript: openTab(tabName) 함수를 사용하여 탭 클릭 시 해당 내용만 표시하고 버튼을 활성화하는 동적 인터랙션 구현

- 핵심 기능
1. 탭 내비게이션:
    상단의 탭 메뉴를 클릭하면 해당 얼굴형의 정보 섹션이 나타남.
    선택된 탭은 하단에 굵은 선으로 강조되어 사용자가 현재 보고 있는 콘텐츠를 명확하게 알수 있음.

2. 얼굴형별 상세 정보 제공:
    주요 특징: 얼굴형의 설명 및 대표 연예인 언급
    
    추천 이미지: 해당 얼굴형에 적합한 헤어스타일 이미지 3장을 시각적으로 제공
    
    스타일링 전략: 얼굴형의 단점을 보완하고 장점을 살리는 구체적인 헤어 전략 목록 제공

3. 반응형 디자인: 
    모바일 환경에서는 탭 버튼의 크기가 줄어들고, 이미지 캘러리가 3열에서 1열로 자동 전환

- JavaScript 동작 상세

openTab(tabName): 탭 전환의 핵심 함수
                1. 모든 tab-content (얼굴형 상세 섹션)에서 active 클랙스를 제거하여 숨김
                2. 모든 tab-button에서 active 클래스를 제거하여 비활성화함
                3. 인수로 받은 tabName에 해당하는 콘텐츠와 버튼에 active 클래스를 추가하여 표시하고 활성화
        
goToIndex(): 하단의 "처음으로" 버튼 클릭 시 메인 페이지(index.html)로 이동
